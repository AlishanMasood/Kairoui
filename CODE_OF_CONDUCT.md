# Code of Conduct

## Placeholder

A formal Code of Conduct has not yet been adopted for KairoUI.

When selected, this file will contain the full text of the chosen standard. The [Contributor Covenant](https://www.contributor-covenant.org/) (v2.1) is the leading candidate.

## Interim Expectations

Until a formal Code of Conduct is adopted:

- Treat all contributors with respect and professionalism.
- Focus feedback on the work, not the person.
- Assume good intent. Ask clarifying questions before criticizing.
- Do not tolerate harassment, discrimination, or personal attacks.
- Maintainers reserve the right to remove disruptive participants.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers directly. Reports will be handled confidentially.
