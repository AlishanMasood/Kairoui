## Findings

### FIXED — Turbo cache inputs incomplete

**Severity**: Medium
**Description**: `turbo.json` build task inputs only listed `src/**`, missing `scripts/**` and `tsconfig.build.json`. Changes to CSS generation scripts or build tsconfig would not invalidate turbo cache.
**Resolution**: Added `scripts/**` and `tsconfig.build.json` to the build task inputs.

### OBSERVATION — No minification (by design)

**Severity**: None (informational)
**Description**: Library packages do not minify JS output. This is the correct approach — consumer bundlers (webpack, vite, esbuild) handle minification and can optimize better with full source.
**Status**: No action needed.

### OBSERVATION — process.env.NODE_ENV preserved correctly

**Severity**: None (informational)
**Description**: The `warning()`, `warnOnce()`, and `errorOnce()` functions in `@kairoui/utils` use `process.env.NODE_ENV !== "production"` to gate dev-only code. This reference is correctly preserved in the built output, allowing consumer bundlers to dead-code-eliminate these paths in production.
**Status**: Working as intended.

### OBSERVATION — DTS chunk hash filenames in @kairoui/theme

**Severity**: Low
**Description**: The theme package's DTS output includes shared type chunks with content-hash filenames (e.g., `types-CCvLZ4Ny.d.ts`). These are generated by rollup-plugin-dts when multiple entry points share type definitions. Verified that hashes are content-based and deterministic across builds.
**Status**: Monitoring — no action needed unless hashes become non-deterministic.

### OBSERVATION — CSS generation script uses eslint-disable

**Severity**: Low
**Description**: `packages/core/scripts/generate-css.ts` requires `eslint-disable` because the file is outside tsconfig scope (resolved via `allowDefaultProject`). Type safety is reduced for this build script.
**Status**: Acceptable for build tooling. Could be improved by adding a dedicated `tsconfig.scripts.json` in a future hardening pass.

### OBSERVATION — React externalization correct

**Severity**: None (informational)
**Description**: All packages correctly externalize React (`import ... from 'react'`). React is never bundled into library output. Peer dependency range is `^18.0.0 || ^19.0.0`.
**Status**: Correct.

### OBSERVATION — Side effects correctly declared

**Severity**: None (informational)
**Description**: CSS-containing packages declare `"sideEffects": ["**/*.css"]`. Pure-logic packages declare `"sideEffects": false`. This enables bundler tree-shaking.
**Status**: Correct.

### OBSERVATION — Build reproducibility verified

**Severity**: None (informational)
**Description**: Clean builds produce identical SHA-256 hashes for all outputs (JS, CSS, DTS) across consecutive runs. Verified for @kairoui/core (3 artifacts) and @kairoui/theme (filenames + content).
**Status**: Deterministic.

### OBSERVATION — Source maps present in dist

**Severity**: None (informational)
**Description**: All packages generate `.js.map` source maps in dist. These are valuable for debugging but add to package size. Architecture decision is to keep them.
**Status**: Correct per project standards.
