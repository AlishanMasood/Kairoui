# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in KairoUI, **do not open a public issue**.

Instead, please report it privately:

1. **Email:** Send details to the project maintainers at the contact address listed in the repository settings.
2. **GitHub Security Advisories:** Use the "Report a vulnerability" button on the repository's Security tab (if enabled).

Include:

- A description of the vulnerability.
- Steps to reproduce.
- The potential impact.
- Any suggested fix, if you have one.

## Response

- We will acknowledge receipt within **3 business days**.
- We will provide an initial assessment within **10 business days**.
- We will coordinate a fix and disclosure timeline with you before making any public announcement.

## Scope

This policy applies to the KairoUI repository and its published packages. It does not cover third-party dependencies — report those to the respective maintainers.

## Supported Versions

Only the latest release is supported with security fixes. Older versions do not receive backports.
