# docs/

Product, architecture, governance, and contributor documentation for the KairoUI project.

This directory holds long-form documentation that is **not** part of a publishable package.

## Structure

```
docs/
├── architecture/   — ADRs and system design documents
├── contributing/   — Contributor guides and conventions
└── governance/     — Decision records, RFC process, release policy
```

> Subdirectories will be populated as governance and architecture decisions are formalized.
