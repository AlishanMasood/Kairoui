# packages/

Publishable KairoUI packages.

Each subdirectory is an independently versioned and publishable package registered as a pnpm workspace member.

## Planned packages

| Package      | Purpose                                                |
| ------------ | ------------------------------------------------------ |
| `core`       | Foundation primitives, design tokens, and theme engine |
| `components` | Enterprise UI component library                        |
| `icons`      | Icon system                                            |
| `utils`      | Shared utilities                                       |

> Packages will be created in subsequent tasks. Do not add packages here without a corresponding task.
