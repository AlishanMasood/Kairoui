# @kairoui-pro/command

Enterprise Command Palette for KairoUI. Ships in the KairoUI Pro tier
built on `@kairoui/core` overlay and collection primitives.

## Status

Package skeleton — component implemented (KUI-ENT-008). Nested-page
navigation, custom filtering, and consumer-provided execution are all
supported. See `docs/architecture/PHASE14-ENTERPRISE-ARCHITECTURE.md`
for the licensing boundary and dependency direction.
