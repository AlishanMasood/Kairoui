# @kairoui/tokens

Design tokens defining color, spacing, typography, and other visual constants for the KairoUI design system.

## Responsibilities

- Color palettes and semantic color mappings
- Spacing and sizing scales
- Typography definitions (font families, sizes, weights, line heights)
- Border radii, shadows, z-indices
- Motion and animation tokens
- Token format output (CSS custom properties, JS objects)
