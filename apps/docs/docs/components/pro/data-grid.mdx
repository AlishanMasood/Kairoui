## Sorting

Click a column header to cycle unsorted → ascending → descending. Hold
`Shift` (or set `multiSort={true}`) to add secondary sort keys.

column. The selected row IDs are exposed via `selectedIds`
(controlled) or `defaultSelectedIds` (uncontrolled).

## Grouping and aggregation

Pass `defaultGroupBy` with column IDs to group rows hierarchically.
Any column with an `aggregate` spec surfaces per-group summary values
and, when `aggregate.footer === true`, a grand-total row (opt-in via
`showAggregatedFooter`).

<Demo
  title="Grouped by team with aggregates"

## Row virtualization

Turn on `virtualized` and provide `rowHeight` (required) to render only
the rows in view. `virtualScrollHeight` sets the scroll container
height in CSS pixels.

## Keyboard model

DataGrid uses the WAI-ARIA `grid` pattern with roving tabindex —
exactly one cell has `tabindex={0}` at any time.

| Key                        | Action                                                     |
| -------------------------- | ---------------------------------------------------------- |
| `ArrowUp` / `ArrowDown`    | Move focus by one row                                      |
| `ArrowLeft` / `ArrowRight` | Move focus by one column (inverted in RTL)                 |
| `Home` / `End`             | First / last column of the current row                     |
| `Ctrl+Home` / `Ctrl+End`   | Top-left / bottom-right of the grid                        |
| `PageUp` / `PageDown`      | Move focus by one viewport of rows                         |
| `Enter` / `F2`             | Begin cell edit (when `editMode` is set and column allows) |
| `Escape`                   | Cancel the active edit                                     |
| `Space`                    | Toggle row selection (when selection is enabled)           |

## Editing

Set `editMode` to `"cell"`, `"row"`, or `"batch"`. Columns opt in
individually with `editable: true` and a `editCell` renderer.
DataGrid never persists on its own — `onCellEdit` and `onRowEdit`
carry plain-data events for the consumer to apply.

```tsx
<DataGrid
  data={data}
  columns={[
    {
      id: "salary",
      header: "Salary",
      accessorKey: "salary",
      editable: true,
      parseEdit: (v) => Number(v),
      validateEdit: (v) => {
        const n = Number(v);
        return Number.isFinite(n) && n >= 0
          ? { ok: true }
          : { ok: false, message: "must be non-negative" };
      },
      editCell: (ctx) => (
        <input
          autoFocus
          defaultValue={String(ctx.rawInput ?? "")}
          onChange={(e) => ctx.setInput(e.target.value)}
          onKeyDown={(e) => {
            if (e.key === "Enter") ctx.commit();
            if (e.key === "Escape") ctx.cancel();
          }}
        />
      ),
    },
  ]}
  getRowId={(row) => row.id}
  editMode="cell"
  onCellEdit={(event) => {
    // event.rowId, event.columnId, event.rawInput, event.value
    persistToBackend(event);
  }}
/>
```

## Server-controlled state

Every stateful concern is controllable. Pair the `state` prop with an
`onStateChange` callback and skip the internal computation with the
matching `serverX` flag when applicable:

- `sort` + `onSortChange` + `serverSort`
- `filterState` + `onFilterStateChange` + `serverFilter`
- `selectedIds` + `onSelectionChange`
- `columnSizing`, `columnOrder`, `columnPinning`, `columnVisibility`
- `groupBy`, `expanded`
- `editingState`, `focusState`

DataGrid never fetches data. Consumers own the query, the mutation, and
the persistence.

## Deferred capability

Pivot tables, spreadsheet formulas, column virtualization, and export
file emitters (CSV / XLSX) are **not** in the initial DataGrid release
and require a separately approved task.
