<DocsSection title="API">

| Prop              | Type                         | Default         | Description                |
| ----------------- | ---------------------------- | --------------- | -------------------------- |
| `children`        | `ReactNode`                  | —               | Label content              |
| `checked`         | `boolean`                    | —               | Controlled checked state   |
| `defaultChecked`  | `boolean`                    | `false`         | Uncontrolled initial state |
| `onCheckedChange` | `(checked: boolean) => void` | —               | Change callback            |
| `size`            | `"sm" \| "md" \| "lg"`       | `"md"`          | Size variant               |
| `disabled`        | `boolean`                    | `false`         | Disables the switch        |
| `name`            | `string`                     | —               | Form submission name       |
| `value`           | `string`                     | `"on"`          | Form submission value      |
| `id`              | `string`                     | auto from Field | Button element ID          |
| `ref`             | `Ref<HTMLButtonElement>`     | —               | Forwarded to button        |

</DocsSection>

<Callout type="info" title="Switch vs Checkbox">
  Switch uses `role="switch"` and a `<button>` element — semantically distinct from Checkbox.
  Use Switch for settings that take effect immediately. Use Checkbox for options that require
  form submission to apply.
</Callout>

<Callout type="info" title="Form participation">
  When `name` is provided, Switch renders a hidden `<input type="checkbox">` for native
  form submission. The hidden input is `aria-hidden` and not keyboard-focusable.
</Callout>
