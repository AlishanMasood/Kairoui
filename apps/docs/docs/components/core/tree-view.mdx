<DocsSection title="Keyboard Navigation">

| Key               | Action                      |
| ----------------- | --------------------------- |
| `ArrowRight`      | Expand collapsed branch     |
| `ArrowLeft`       | Collapse expanded branch    |
| `Enter` / `Space` | Toggle expand and/or select |
| `Tab`             | Move between triggers       |

RTL reverses ArrowLeft/ArrowRight behavior.

</DocsSection>

<DocsSection title="Accessibility">

- Root has `role="tree"` with `<ul>` element
- Items have `role="treeitem"` with `<li>` element
- Nested content uses `role="group"` with `<ul>` element
- `aria-expanded` on branch items reflects expand state
- `aria-selected` on items when selection mode is active
- `aria-disabled` on disabled items
- Indicator is `aria-hidden` (decorative)
- `data-depth` attribute enables indentation styling

</DocsSection>
