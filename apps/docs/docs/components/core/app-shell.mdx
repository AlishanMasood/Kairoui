<DocsSection title="CSS Custom Properties">

AppShell exposes layout dimensions as CSS custom properties for child styling:

| Property                    | Description                              |
| --------------------------- | ---------------------------------------- |
| `--kui-shell-header-height` | Header row height                        |
| `--kui-shell-sidebar-width` | Sidebar column width (respects collapse) |
| `--kui-shell-aside-width`   | Aside column width                       |
| `--kui-shell-footer-height` | Footer row height                        |

</DocsSection>

<DocsSection title="Accessibility">

- Uses semantic HTML elements: `<header>`, `<aside>`, `<main>`, `<footer>`
- Implicit landmark roles: `banner`, `complementary`, `main`, `contentinfo`
- No ARIA attributes needed — native semantics provide full accessibility
- Grid layout preserves DOM order for screen reader navigation

</DocsSection>
