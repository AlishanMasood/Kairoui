<DocsSection title="Accessibility">

- Renders as `<nav>` with `aria-label` (navigation landmark)
- Uses `<ol>` / `<li>` for ordered list semantics
- Separators hidden from screen readers via `aria-hidden="true"` and `role="presentation"`
- Current page marked with `aria-current="page"`
- Links are native `<a>` elements — no custom roles needed

</DocsSection>
