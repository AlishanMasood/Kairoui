<DocsSection title="Accessibility">

- Renders as `<nav>` with `aria-label="Pagination"` (customizable)
- Current page indicated with `aria-current="page"`
- Previous/Next buttons have descriptive `aria-label`
- Disabled buttons use `aria-disabled` (remain discoverable)
- Ellipsis hidden from screen readers via `aria-hidden="true"`
- Page buttons have `aria-label="Page N"` when rendering as buttons

</DocsSection>
