<Callout type="warning" title="Accessible name required">
  IconButton emits a console error in development if neither `aria-label` nor `aria-labelledby` is
  provided. Every IconButton must have an accessible name — visually hidden text is not sufficient
  because the icon slot is marked `aria-hidden`.
</Callout>

<Callout type="tip" title="When to use IconButton vs Button">
  Use IconButton for compact, icon-only actions like close, settings, or navigation toggles. If you
  need visible text alongside an icon, use Button with `startIcon` or `endIcon` instead.
</Callout>
