<Callout type="info" title="TimeOfDay is timezone-free">
  Time-only values never coerce through `Date`. `TimeInput` accepts and emits `TimeOfDay`
  (`{ hour, minute, second, millisecond }`) from `@kairoui/utils/date`.
</Callout>

<DocsSection title="12- vs 24-hour presentation">

The clock format follows the locale by default (`en-US` uses AM/PM; `en-GB` uses 24-hour). Pass
`hour12` to force one form.

<Demo
  code={`<TimeInput locale="en-US" />        {/* 12-hour */}
<TimeInput locale="en-GB" />        {/* 24-hour */}
<TimeInput locale="en-US" hour12={false} />`}
>
  <div style={{ display: "flex", flexDirection: "column", gap: 8, maxWidth: 240 }}>
    <TimeInput locale="en-US" />
    <TimeInput locale="en-GB" />
    <TimeInput locale="en-US" hour12={false} />
  </div>
</Demo>

</DocsSection>

<DocsSection title="Seconds and step">

Pass `includeSeconds` to display and validate seconds. `step` (in seconds) snaps parsed values to
the nearest multiple. When `step < 60`, `includeSeconds` defaults to `true`.

<Demo
  code={`<TimeInput hour12={false} step={30} />           {/* 30-second granularity */}
<TimeInput hour12={false} step={900} />          {/* 15-minute step */}
<TimeInput hour12={false} includeSeconds />       {/* show seconds explicitly */}`}
>
  <div style={{ display: "flex", flexDirection: "column", gap: 8, maxWidth: 240 }}>
    <TimeInput hour12={false} step={30} />
    <TimeInput hour12={false} step={900} />
    <TimeInput hour12={false} includeSeconds />
  </div>
</Demo>

</DocsSection>

<DocsSection title="Native form submission">

`TimeInput` writes an ISO time (`HH:MM` or `HH:MM:SS` when seconds are shown) to a hidden `<input>`
under `name`. No timezone conversion is applied — the value is exactly what the user typed.

</DocsSection>

<DocsSection title="Keyboard">

- **Enter** — commits and blurs
- **Escape** — reverts to the last committed value and blurs
- **Tab** — commits on blur

</DocsSection>

<DocsSection title="Accessibility">

- `aria-invalid="true"` on failed parse or out-of-range values
- Integrates with `Field` — inherits `disabled`, `readOnly`, `required`, `invalid`
- `aria-describedby` and `aria-errormessage` are wired automatically inside `Field`
- `data-min`, `data-max`, `data-step`, `data-hour12` exposed for tooling and CSS hooks

</DocsSection>
