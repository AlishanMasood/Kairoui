<DocsSection title="Basic Usage">

Field generates stable IDs and connects Label, FieldDescription, and FieldError to any control via `aria-labelledby`, `aria-describedby`, and `aria-errormessage`.

<Demo
  code={`<Field id="email" required>
  <Label>Email address</Label>
  <Input type="email" placeholder="you@example.com" />
  <FieldDescription>We'll never share your email.</FieldDescription>
</Field>`}
>
  <Field id="email-demo1" required>
    <div style={{ display: "flex", flexDirection: "column", gap: "4px", maxWidth: "320px" }}>
      <Label>Email address</Label>
      <Input type="email" placeholder="you@example.com" />
      <FieldDescription style={{ fontSize: "0.85em", color: "#666" }}>
        We'll never share your email.
      </FieldDescription>
    </div>
  </Field>
</Demo>

</DocsSection>

<DocsSection title="With Validation Error">

Set `validationState="invalid"` to mark the field as invalid. FieldError renders as a live region.

<Demo
  code={`<Field id="password" required validationState="invalid">

  <Input type="password" />
  <FieldDescription>Minimum 8 characters</FieldDescription>
  <FieldError>Password is too short</FieldError>
</Field>`}
>
  <Field id="pw-demo1" required validationState="invalid">
    <div style={{ display: "flex", flexDirection: "column", gap: "4px", maxWidth: "320px" }}>
      <Label>Password</Label>
      <Input type="password" />

        Minimum 8 characters
      </FieldDescription>
      <FieldError style={{ fontSize: "0.85em", color: "red" }}>
        Password is too short
      </FieldError>
    </div>
  </Field>
</Demo>

</DocsSection>

<DocsSection title="Field API">

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | auto-generated | Base ID for ARIA relationships |
| `disabled` | `boolean` | `false` | Disables all controls |
| `readOnly` | `boolean` | `false` | Makes controls read-only |
| `required` | `boolean` | `false` | Marks as required |
| `validationState` | `"valid" \| "invalid"` | — | Validation state |
| `ref` | `Ref<HTMLDivElement>` | — | Forwarded ref |
| `className` | `string` | — | Custom class |
| `style` | `CSSProperties` | — | Inline styles |

</DocsSection>

<Callout type="info" title="Automatic ARIA wiring">
  Field generates stable IDs and connects them automatically. Label gets `htmlFor` pointing to the
  control's ID. Controls get `aria-labelledby`, `aria-describedby`, and `aria-errormessage` based
  on which Field sub-components are rendered.
</Callout>

<Callout type="tip" title="Standalone controls">
  All controls (Input, Textarea, Checkbox, Radio, Switch) work without Field. Field is optional
  convenience — use it when you need label/description/error association.
</Callout>

<Callout type="warning" title="No automatic validation">
  Field does not validate input values. Set `validationState` based on your own validation logic
  or your form library's state.
</Callout>
