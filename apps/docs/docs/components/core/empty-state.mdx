<DocsSection title="Accessibility">

- Root has `role="status"` — screen readers announce it as a live region
- Icon slot uses `aria-hidden="true"` — decorative content hidden from AT
- Title renders as `<h3>` for document outline
- Description renders as `<p>` for proper text semantics
- Actions slot contains interactive elements (buttons/links) that remain in tab order

</DocsSection>
