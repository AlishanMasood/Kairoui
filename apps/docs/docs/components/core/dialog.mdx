<DocsSection title="Anatomy">

| Part                | Description                               |
| ------------------- | ----------------------------------------- |
| `Dialog`            | Root, manages open state and context      |
| `DialogTrigger`     | Button that toggles the dialog            |
| `DialogPortal`      | Portals content to document.body          |
| `DialogBackdrop`    | Decorative backdrop overlay               |
| `DialogContent`     | The dialog panel (role="dialog")          |
| `DialogTitle`       | Accessible title (aria-labelledby)        |
| `DialogDescription` | Accessible description (aria-describedby) |
| `DialogClose`       | Button that closes the dialog             |

</DocsSection>

<DocsSection title="Accessibility">

<Callout type="info">
  Every Dialog must include a `DialogTitle` for screen readers. The content automatically receives
  `role="dialog"`, `aria-modal="true"`, and links to the title via `aria-labelledby`.
</Callout>

- Focus is trapped within the dialog while open
- Escape key closes the dialog
- Focus returns to the trigger on close

</DocsSection>
