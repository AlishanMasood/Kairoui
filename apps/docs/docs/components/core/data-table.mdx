<DocsSection title="Column Filter — text input">

Filter UI is composable — you build the widget with any `Input` and wire it to the shared filter
state via `useColumnFilter`. The DataTable exposes `id` so the filter widget can reference it via
`aria-controls`.

export const TextFilterDemo = () => {
  const store = useFilterState();
  const nameFilter = useColumnFilter({
    columnId: "name",
    filterState: store.filterState,
    setColumnFilter: store.setColumnFilter,
    defaultOp: "contains",
  });
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: "0.75rem" }}>
      <Input
        value={String(nameFilter.value ?? "")}
        onChange={(e) => nameFilter.setValue(e.target.value)}
        placeholder="Filter by name…"
        aria-controls="users-text-filter-table"
        aria-label="Filter users by name"
      />
      <DataTable
        id="users-text-filter-table"
        data={users}
        columns={cols}
        getRowId={(u) => u.id}
        filterState={store.filterState}
        onFilterStateChange={store.setFilterState}
        filteredEmptyState={
          <div style={{ padding: "1rem", opacity: 0.7 }}>No users match that filter.</div>
        }
      />
    </div>
  );
};

<DocsSection title="Column Filter — select">

For enumerable columns, use any Select widget and drive the filter with the `equals` operator.

<DocsSection title="Global search">

Compose `useGlobalSearch` with `useFilterState` for debounced free-text search across every
filterable column. The debounce runs in `useGlobalSearch`; the DataTable receives the settled
value.

export const GlobalSearchDemo = () => {
  const store = useFilterState();
  const search = useGlobalSearch({ delayMs: 200 });
  useEffect(() => {
    store.setGlobalFilter(search.debounced);
  }, [search.debounced]);
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: "0.75rem" }}>
      <Input
        value={search.input}
        onChange={(e) => search.setInput(e.target.value)}
        placeholder="Search users…"
        aria-controls="users-global-search-table"
        aria-label="Search users"
      />
      <DataTable
        id="users-global-search-table"
        data={users}
        columns={cols}
        getRowId={(u) => u.id}
        filterState={store.filterState}
        onFilterStateChange={store.setFilterState}
        filteredEmptyState={<div style={{ padding: "1rem", opacity: 0.7 }}>No matches.</div>}
      />
    </div>
  );
};

<DocsSection title="Server-controlled filtering">

Data fetching stays outside the component. Wire `onFilterStateChange` to your query layer and
feed the filtered rows back through `data`. `filterState` is plain data — serialize with
`JSON.stringify` and send it to any backend.

```tsx
const [rows, setRows] = React.useState([]);
const [filterState, setFilterState] = React.useState(EMPTY_FILTER_STATE);

React.useEffect(() => {
  fetch("/api/users?filter=" + encodeURIComponent(JSON.stringify(filterState)))
    .then((r) => r.json())
    .then(setRows);
}, [filterState]);

<DataTable
  data={rows}
  columns={cols}
  getRowId={(u) => u.id}
  filterState={filterState}
  onFilterStateChange={setFilterState}
/>;
```

</DocsSection>

<DocsSection title="Accessibility">

- Built on native `<table>` semantics via the Table component
- Sortable headers use `aria-sort` and respond to Enter/Space
- Selected rows have `aria-selected`
- Select-all header has `aria-label`
- Empty state shown when `data` is empty and not loading

</DocsSection>

| `Enter` / `Space` | Selection cell    | Toggle row selection    |
