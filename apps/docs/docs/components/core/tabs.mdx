<DocsSection title="Manual Activation">

<DocsSection title="Keyboard Navigation">

| Key                        | Action                               |
| -------------------------- | ------------------------------------ |
| `ArrowRight` / `ArrowLeft` | Move focus between tabs (horizontal) |
| `ArrowDown` / `ArrowUp`    | Move focus between tabs (vertical)   |
| `Home` / `End`             | Move to first / last enabled tab     |
| `Enter` / `Space`          | Activate tab (manual mode only)      |
| `Tab`                      | Move into panel content              |

</DocsSection>

<DocsSection title="Accessibility">

- Implements WAI-ARIA [Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)
- Roving tabindex: only the active tab is in the tab sequence
- `role="tablist"`, `role="tab"`, `role="tabpanel"` applied automatically
- `aria-selected`, `aria-controls`, `aria-labelledby` link tabs to panels
- Disabled tabs announced via `aria-disabled`

</DocsSection>
