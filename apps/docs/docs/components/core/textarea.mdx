<DocsSection title="API">

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Size variant |
| `resize` | `"none" \| "vertical" \| "horizontal" \| "both"` | `"vertical"` | Resize behavior |
| `disabled` | `boolean` | `false` | Disables textarea |
| `readOnly` | `boolean` | `false` | Prevents editing |
| `required` | `boolean` | `false` | Marks as required |
| `value` | `string` | — | Controlled value |
| `defaultValue` | `string` | — | Uncontrolled initial value |
| `onChange` | `ChangeEventHandler` | — | Change callback |
| `rows` | `number` | — | Visible text rows |
| `cols` | `number` | — | Visible text columns |
| `name` | `string` | — | Form submission name |
| `placeholder` | `string` | — | Placeholder text |
| `id` | `string` | auto from Field | Element ID |
| `ref` | `Ref<HTMLTextAreaElement>` | — | Forwarded ref |
| `className` | `string` | — | Merged with internal classes |
| `style` | `CSSProperties` | — | Inline styles |

All standard `<textarea>` HTML attributes are also accepted.

</DocsSection>

<Callout type="info" title="Native behavior">
  Textarea uses native form integration. It works with controlled patterns, uncontrolled
  defaultValue, and native form submission without any interception.
</Callout>
