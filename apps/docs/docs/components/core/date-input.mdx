<DocsSection title="Native form submission">

`DateInput` writes an ISO-8601 date (`YYYY-MM-DD`) to a hidden `<input>` when `name` is provided.
The value uses the browser's local calendar — no UTC shift.

</DocsSection>

<DocsSection title="Keyboard">

- **Enter** — commits and blurs
- **Escape** — reverts to the last committed value and blurs
- **Tab** — commits on blur

</DocsSection>

<DocsSection title="Accessibility">

- `aria-invalid="true"` is set when input fails to parse or falls outside min/max
- Integrates with `Field` — inherits `disabled`, `readOnly`, `required`, `invalid`
- `aria-describedby` / `aria-errormessage` are wired automatically inside `Field`
- `data-min` / `data-max` expose the ISO bounds for tooling

</DocsSection>
