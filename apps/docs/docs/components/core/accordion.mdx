<DocsSection title="Keyboard Navigation">

| Key                        | Action                                   |
| -------------------------- | ---------------------------------------- |
| `ArrowDown` / `ArrowUp`    | Move focus between triggers (vertical)   |
| `ArrowRight` / `ArrowLeft` | Move focus between triggers (horizontal) |
| `Home` / `End`             | Move to first / last enabled trigger     |
| `Enter` / `Space`          | Toggle the focused item                  |

</DocsSection>

<DocsSection title="Accessibility">

- Implements WAI-ARIA [Accordion Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/)
- `aria-expanded` on triggers reflects open state
- `aria-controls` links trigger to content region
- Content uses `role="region"` with `aria-labelledby`
- Header renders as proper heading element (`h1`–`h6`)
- Disabled items skipped during keyboard navigation

</DocsSection>
