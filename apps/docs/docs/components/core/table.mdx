<DocsSection title="Accessibility">

- Uses native `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>` elements
- `<caption>` provides an accessible name for the table
- `aria-sort` set on sortable headers (`ascending` / `descending`)
- `aria-selected` set on selected rows
- Sortable headers get `tabIndex=0` and respond to Enter/Space
- `scope`, `colSpan`, `rowSpan` all supported via native attributes

</DocsSection>
