<DocsSection title="Accessibility">

- Renders native `<ul>` or `<ol>` elements — no ARIA roles needed
- Screen readers automatically announce list semantics and item count
- Supports all native list attributes (`start`, `reversed`, `type` for ordered lists)

</DocsSection>
