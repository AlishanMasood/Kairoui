<DocsSection title="Accessibility">

- Renders as `<ol>` with `<li>` items — ordered list semantics convey sequence
- `<time>` element with `dateTime` attribute for machine-readable dates
- Indicator and connector are `aria-hidden` (decorative)
- Title and description use `<p>` elements for text semantics

</DocsSection>
