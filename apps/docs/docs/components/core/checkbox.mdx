<Callout type="info" title="Native form participation">
  Checkbox uses a native `<input type="checkbox">` for full form compatibility.
  Checked checkboxes submit their `name`/`value`; unchecked ones are omitted from FormData.
</Callout>

<Callout type="warning" title="Indeterminate vs Checked">
  `indeterminate` is a visual-only state — it does not affect the `checked` value or form
  submission. It must be managed externally (e.g., by computing whether child items are partially
  selected).
</Callout>
