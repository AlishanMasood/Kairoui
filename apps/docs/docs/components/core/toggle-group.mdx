<Callout type="info" title="Single vs Multiple">
  In `type="single"`, clicking a new item deselects the previous. Clicking the same item deselects
  it. In `type="multiple"`, each item toggles independently — multiple can be pressed
  simultaneously.
</Callout>

<Callout type="info" title="Accessibility">
  Uses `role="group"` with `aria-orientation`. Each item has `aria-pressed`. Enter/Space toggle
  items via native button behavior.
</Callout>
