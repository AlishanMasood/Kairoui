<DocsSection title="Key Differences from Dialog">

| Behavior                | Dialog         | AlertDialog   |
| ----------------------- | -------------- | ------------- |
| Role                    | `dialog`       | `alertdialog` |
| Outside click dismisses | Yes            | No            |
| Initial focus           | First tabbable | Cancel button |
| Modal                   | Configurable   | Always        |

</DocsSection>
