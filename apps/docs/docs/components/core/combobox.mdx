<DocsSection title="Basic Usage">

Consumer controls filtering via `onInputValueChange`. Items are rendered declaratively.

</DocsSection>

<DocsSection title="Keyboard">

- **ArrowDown/Up** — navigate items
- **Home/End** — first/last item
- **Enter** — select highlighted item
- **Escape** — close listbox
- **Tab** — close and move focus

</DocsSection>

<Callout type="info" title="Filtering is consumer responsibility">
  Combobox fires `onInputValueChange` on every keystroke. You filter and render items declaratively.
  This keeps async, fuzzy, and server-side filtering possible.
</Callout>
