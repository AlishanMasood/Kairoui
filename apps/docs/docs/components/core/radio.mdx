<DocsSection title="API">

| Prop              | Type                         | Default         | Description                  |
| ----------------- | ---------------------------- | --------------- | ---------------------------- |
| `children`        | `ReactNode`                  | —               | Label content                |
| `value`           | `string`                     | `"on"`          | Form submission value        |
| `checked`         | `boolean`                    | —               | Controlled checked state     |
| `defaultChecked`  | `boolean`                    | `false`         | Uncontrolled initial state   |
| `onCheckedChange` | `(checked: boolean) => void` | —               | Change callback (standalone) |
| `size`            | `"sm" \| "md" \| "lg"`       | `"md"`          | Size variant                 |
| `disabled`        | `boolean`                    | `false`         | Disables the radio           |
| `required`        | `boolean`                    | `false`         | Marks as required            |
| `name`            | `string`                     | —               | Form submission name         |
| `id`              | `string`                     | auto from Field | Input element ID             |
| `ref`             | `Ref<HTMLInputElement>`      | —               | Forwarded to native input    |

</DocsSection>

<Callout type="info" title="RadioGroup integration">
  When used inside a RadioGroup (KUI-CORE-013), Radio automatically receives its `name`, `checked`
  state, `disabled`, and `required` from group context. The `onCheckedChange` prop is ignored in
  favor of the group's `onValueChange`.
</Callout>

<Callout type="info" title="Native behavior">
  Radio uses a native `<input type="radio">` for built-in form submission and accessibility.
  Only the selected radio in a name group submits its value.
</Callout>
