<DocsSection title="Accessibility">

- `<aside>` element provides implicit `complementary` landmark
- `SidebarContent` has `role="navigation"` for the nav section
- `SidebarGroup` uses `role="group"`
- Collapsible group labels render as buttons with `aria-expanded`
- Active links marked with `aria-current="page"`
- Disabled links have `aria-disabled` and remove `href`
- `SidebarTrigger` has `aria-expanded` and `aria-label`

</DocsSection>
