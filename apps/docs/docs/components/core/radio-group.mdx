<DocsSection title="API">

| Prop            | Type                         | Default         | Description                   |
| --------------- | ---------------------------- | --------------- | ----------------------------- |
| `value`         | `string`                     | —               | Controlled selected value     |
| `defaultValue`  | `string`                     | —               | Uncontrolled initial value    |
| `onValueChange` | `(value: string) => void`    | —               | Selection change callback     |
| `name`          | `string`                     | auto-generated  | Shared name for all radios    |
| `disabled`      | `boolean`                    | `false`         | Disables all radios           |
| `required`      | `boolean`                    | `false`         | At least one must be selected |
| `orientation`   | `"vertical" \| "horizontal"` | `"vertical"`    | Layout direction              |
| `id`            | `string`                     | auto from Field | Group element ID              |
| `ref`           | `Ref<HTMLDivElement>`        | —               | Forwarded ref                 |
| `className`     | `string`                     | —               | Custom class                  |
| `style`         | `CSSProperties`              | —               | Inline styles                 |

</DocsSection>

<Callout type="info" title="Keyboard navigation">
  Native radio groups with a shared `name` attribute provide built-in arrow-key navigation.
  RadioGroup generates a shared name automatically, so arrow keys work without custom handlers.
</Callout>

<Callout type="tip" title="Form submission">
  Only the selected radio's `value` is submitted. If no radio is selected, nothing is submitted for
  that name. Use `required` to enforce selection.
</Callout>
