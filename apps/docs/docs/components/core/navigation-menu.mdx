<DocsSection title="Active Link">

<Demo
  code={`<NavigationMenu>

<DocsSection title="Keyboard Navigation">

| Key                             | Action                              |
| ------------------------------- | ----------------------------------- |
| `ArrowDown` / `Enter` / `Space` | Open content panel                  |
| `Tab`                           | Navigate between triggers and links |
| Click outside / Pointer leave   | Close content panel                 |

</DocsSection>

<DocsSection title="Accessibility">

- Renders as `<nav>` landmark with configurable `aria-label`
- Triggers have `aria-haspopup="true"`, `aria-expanded`, and `aria-controls`
- Active links use `aria-current="page"`
- Content panel linked via `aria-labelledby` to its trigger
- Hover-based opening uses configurable `delayDuration` (default 200ms)

</DocsSection>
