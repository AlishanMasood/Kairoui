<DocsSection title="Keyboard Navigation">

| Key               | Action              |
| ----------------- | ------------------- |
| `ArrowRight`      | Next day            |
| `ArrowLeft`       | Previous day        |
| `ArrowDown`       | Next week           |
| `ArrowUp`         | Previous week       |
| `Enter` / `Space` | Select focused date |

RTL mode reverses ArrowRight/ArrowLeft.

</DocsSection>

<DocsSection title="Accessibility">

- Uses `role="grid"` with `role="gridcell"` for days
- `aria-selected` on selected date
- `aria-disabled` on disabled dates
- `aria-label` on the grid shows current month/year
- `aria-live="polite"` on heading announces month changes
- Previous/Next buttons have `aria-label`
- Roving tabindex: only focused day has `tabIndex=0`

</DocsSection>
