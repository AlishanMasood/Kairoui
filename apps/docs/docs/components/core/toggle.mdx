<DocsSection title="API">

| Prop              | Type                               | Default     | Description              |
| ----------------- | ---------------------------------- | ----------- | ------------------------ |
| `pressed`         | `boolean`                          | —           | Controlled pressed state |
| `defaultPressed`  | `boolean`                          | `false`     | Initial state            |
| `onPressedChange` | `(pressed: boolean) => void`       | —           | Change callback          |
| `size`            | `"sm" \| "md" \| "lg"`             | `"md"`      | Size variant             |
| `appearance`      | `"outline" \| "subtle" \| "ghost"` | `"outline"` | Visual variant           |
| `disabled`        | `boolean`                          | `false`     | Disables the toggle      |

</DocsSection>

<Callout type="info" title="Toggle vs Switch">
  **Toggle** uses `aria-pressed` on a native `<button>` — represents a toolbar action that can be toggled (e.g., Bold, Italic, Mute).
  **Switch** uses `role="switch"` with `aria-checked` — represents a setting that takes effect immediately (e.g., Dark mode, Notifications).
</Callout>
