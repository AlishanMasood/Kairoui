<Callout type="info" title="Emits DateRange">
  DateRangePicker emits a `DateRange` shape (`{ start: Date | null; end: Date | null }`). Partial
  ranges are emitted by default; opt into buffered complete-only emissions with `requireComplete`.
</Callout>

<DocsSection title="Anatomy">

side by side with hover preview.

<DocsSection title="Disabled dates">

Same predicate contract as `DatePicker` and `Calendar`. Cells that fail the predicate are
un-focusable and un-clickable in both months.

<Demo
  code={`<DateRangePicker

  disabledDate={(d) => d.getDay() === 0 || d.getDay() === 6}

  <DateRangePickerTrigger />

<DocsSection title="Length constraints">

Enforce a minimum or maximum span with `minLength` / `maxLength` (in days, inclusive of both
endpoints). Cells beyond `maxLength` from the pending start are visually dimmed and rejected.

<Demo
  code={`<DateRangePicker locale="en-US" minLength={2} maxLength={14}>

</DateRangePicker>`}

<DocsSection title="Complete ranges only">

`requireComplete` buffers the start commit internally and only emits `onValueChange` once the
end is picked. Useful for form-driven flows where a partial range is invalid.

<Demo
  code={`<DateRangePicker locale="en-US" requireComplete>
  <DateRangePickerStartInput />
  <DateRangePickerEndInput />
  <DateRangePickerTrigger />
  <DateRangePickerContent><DateRangePickerCalendars /></DateRangePickerContent>
</DateRangePicker>`}
>
  <DateRangePicker locale="en-US" requireComplete>
    <DateRangePickerStartInput />
    <DateRangePickerEndInput />
    <DateRangePickerTrigger />
    <DateRangePickerContent>
      <DateRangePickerCalendars />
    </DateRangePickerContent>
  </DateRangePicker>
</Demo>

</DocsSection>

<DocsSection title="Field integration">

Compose inside a `Field` for label, description, and error handling. Only the start input
carries `aria-errormessage`; the end input carries `aria-describedby` for description slots.

<DocsSection title="Form serialization">

When `name` is provided, two hidden inputs are emitted as `${name}.start` and `${name}.end`,
each holding an ISO `YYYY-MM-DD` string.

</DocsSection>
