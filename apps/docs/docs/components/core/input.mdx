<DocsSection title="With Field">

Inside a Field, Input automatically receives the correct `id`, `aria-labelledby`, `aria-describedby`, and validation attributes.

<Demo
  code={`<Field id="email" required>
  <Label>Email address</Label>
  <Input type="email" placeholder="you@example.com" />
  <FieldDescription>We'll never share your email.</FieldDescription>
</Field>`}
>
  <Field id="email-demo" required>
    <div style={{ display: "flex", flexDirection: "column", gap: "4px", maxWidth: "300px" }}>
      <Label>Email address</Label>
      <Input type="email" placeholder="you@example.com" />
      <FieldDescription style={{ fontSize: "0.85em", color: "#666" }}>
        We'll never share your email.
      </FieldDescription>
    </div>
  </Field>
</Demo>

</DocsSection>

<DocsSection title="API">

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Size variant |
| `type` | `string` | `"text"` | Native input type |
| `disabled` | `boolean` | `false` | Disables input |
| `readOnly` | `boolean` | `false` | Prevents editing |
| `required` | `boolean` | `false` | Marks as required |
| `value` | `string` | — | Controlled value |
| `defaultValue` | `string` | — | Uncontrolled initial value |
| `onChange` | `ChangeEventHandler` | — | Change callback |
| `name` | `string` | — | Form submission name |
| `placeholder` | `string` | — | Placeholder text |
| `id` | `string` | auto from Field | Element ID |
| `ref` | `Ref<HTMLInputElement>` | — | Forwarded ref |
| `className` | `string` | — | Merged with internal classes |
| `style` | `CSSProperties` | — | Inline styles |

All standard `<input>` HTML attributes are also accepted.

</DocsSection>

<Callout type="info" title="Native behavior">
  Input does not intercept native form submission, value handling, or validation.
  It works seamlessly with native forms, React controlled patterns, and form libraries.
</Callout>
