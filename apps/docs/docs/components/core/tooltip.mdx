<DocsSection title="Accessibility">

<Callout type="info">
  Tooltip uses `role="tooltip"` and links to the trigger via `aria-describedby`. It is
  non-interactive — content cannot be hovered or focused. Use Popover for interactive floating
  content.
</Callout>
