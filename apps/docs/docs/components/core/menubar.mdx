<DocsSection title="Keyboard Navigation">

| Key                             | Context   | Action                         |
| ------------------------------- | --------- | ------------------------------ |
| `ArrowRight`                    | Menubar   | Move focus to next trigger     |
| `ArrowLeft`                     | Menubar   | Move focus to previous trigger |
| `ArrowDown` / `Enter` / `Space` | Trigger   | Open sub-menu                  |
| `ArrowDown` / `ArrowUp`         | Open menu | Navigate menu items            |
| `Home` / `End`                  | Open menu | Jump to first / last item      |
| `Escape`                        | Open menu | Close menu and restore focus   |

When a menu is open, moving between triggers via arrow keys automatically opens the adjacent menu.

</DocsSection>

<DocsSection title="Accessibility">

- `role="menubar"` on root with `aria-orientation="horizontal"`
- Triggers have `role="menuitem"` + `aria-haspopup="menu"` + `aria-expanded`
- Roving tabindex: only one trigger in the tab sequence
- Open menu content has `role="menu"` with `aria-labelledby`
- Focus trapped inside open menu; Escape restores focus to trigger
- RTL-aware arrow key directions

</DocsSection>
