<DocsSection title="Tones">

| Tone      | Usage                         |
| --------- | ----------------------------- |
| `info`    | General information (default) |
| `success` | Positive confirmation         |
| `warning` | Caution, potential issue      |
| `danger`  | Error or destructive outcome  |

</DocsSection>

<DocsSection title="Live Announcements">

<Callout type="info">
  By default Alert has `role="status"` (not announced assertively). Pass `live` to use
  `role="alert"` for dynamic content that must be announced immediately.
</Callout>

</DocsSection>
