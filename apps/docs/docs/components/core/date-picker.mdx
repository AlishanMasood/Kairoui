<Callout type="info" title="No time selection, no ranges">
  DatePicker handles calendar dates only. Use `TimeInput` for time-only values, `DateTimeInput` for
  combined date-time (Phase 13 forthcoming), and `DateRangePicker` for ranges.
</Callout>

<DocsSection title="Disabled dates">

focus and clicks on disabled dates.

<DocsSection title="Controlled / uncontrolled">

DatePicker accepts either `value` (controlled) or `defaultValue` (uncontrolled). The same
pattern applies to the popover with `open` / `defaultOpen`. Emit changes via `onValueChange`
and `onOpenChange`.

<Demo
  code={`function ControlledDatePicker() {
  const [date, setDate] = React.useState(null);
  return (
    <DatePicker value={date} onValueChange={setDate} locale="en-US">
      <DatePickerInput />
      <DatePickerClear />
      <DatePickerTrigger />
      <DatePickerContent><DatePickerCalendar /></DatePickerContent>
    </DatePicker>
  );
}`}
>
  <DatePicker defaultValue={new Date(2026, 5, 15)} locale="en-US">
    <DatePickerInput />
    <DatePickerClear />
    <DatePickerTrigger />
    <DatePickerContent>
      <DatePickerCalendar />
    </DatePickerContent>
  </DatePicker>
</Demo>

</DocsSection>

<DocsSection title="Keyboard">

- **ArrowDown** on the input — opens the popover and focuses the selected day
- **Alt+ArrowUp** on the input — closes the popover
- **Enter / Space** on a calendar day — selects and closes; focus returns to the input
- **Escape** — closes the popover
- **Tab** — normal focus flow; closes the popover if it was open

</DocsSection>

<DocsSection title="Accessibility">

- The input has `role="combobox"`, `aria-haspopup="dialog"`, `aria-expanded`, and `aria-controls`
- The trigger button has `aria-haspopup="dialog"` and `aria-expanded`
- The content has `role="dialog"` and `aria-label="Choose date"`
- The Calendar grid inside inherits `role="grid"` and `aria-selected` / `aria-disabled` on cells
- Focus is trapped inside the popover only for modal Popovers (default is non-modal)
- The clear button has `aria-label="Clear date"`

</DocsSection>

<DocsSection title="Form participation">

DatePicker delegates form participation to `DateInput`. When `name` is set, a hidden `<input>` is
emitted carrying an ISO `YYYY-MM-DD` value (browser-local; no UTC shift).

</DocsSection>
