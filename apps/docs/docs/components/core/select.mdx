<DocsSection title="API: Select">

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Controlled value |
| `defaultValue` | `string` | — | Uncontrolled initial value |
| `onValueChange` | `(value: string) => void` | — | Selection callback |
| `open` | `boolean` | — | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Initial open state |
| `onOpenChange` | `(open: boolean) => void` | — | Open/close callback |
| `name` | `string` | — | Form submission name |
| `disabled` | `boolean` | `false` | Disables the select |
| `required` | `boolean` | `false` | Marks as required |

</DocsSection>

<DocsSection title="API: SelectItem">

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Item value (required) |
| `label` | `string` | text content | Typeahead label |
| `disabled` | `boolean` | `false` | Disables the item |

</DocsSection>

<Callout type="info" title="Keyboard navigation">
  Arrow keys navigate items, Home/End jump to first/last, Enter selects, Escape closes.
  Typing characters performs typeahead search.
</Callout>

<Callout type="info" title="Form participation">
  When `name` is provided, Select renders a hidden `<input type="hidden">` for native form submission.
</Callout>
