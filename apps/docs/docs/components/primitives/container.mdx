<DocsSection title="API">

| Prop       | Type                                               | Default             | Description                      |
| ---------- | -------------------------------------------------- | ------------------- | -------------------------------- |
| `maxWidth` | `"sm" \| "md" \| "lg" \| "xl" \| "full" \| string` | CSS custom property | Max width preset or custom value |
| `gutter`   | `string \| number`                                 | CSS custom property | Horizontal padding               |

Size presets: sm=640px, md=768px, lg=1024px, xl=1200px, full=none.
