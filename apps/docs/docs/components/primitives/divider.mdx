<Callout type="info" title="Accessibility">
  Divider renders a native `hr` element with implicit separator role. Use `decorative` for
  visual-only dividers that should not be announced.
</Callout>

<DocsSection title="API">

| Prop          | Type                         | Default        | Description                         |
| ------------- | ---------------------------- | -------------- | ----------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction                           |
| `decorative`  | `boolean`                    | —              | Sets role="none" for screen readers |

</DocsSection>
