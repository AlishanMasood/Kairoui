<Callout type="tip" title="Stack vs Flex">
  Use Stack for simple vertical/horizontal spacing. Use Flex when you need justify, wrap, or reverse
  direction.
</Callout>

<DocsSection title="API">

| Prop        | Type                                                      | Default      | Description              |
| ----------- | --------------------------------------------------------- | ------------ | ------------------------ |
| `gap`       | `string \| number`                                        | —            | Spacing between children |
| `align`     | `"start" \| "center" \| "end" \| "stretch" \| "baseline"` | —            | Cross-axis alignment     |
| `direction` | `"vertical" \| "horizontal"`                              | `"vertical"` | Stack axis               |

</DocsSection>
