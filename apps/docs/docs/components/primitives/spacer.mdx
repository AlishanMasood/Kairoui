<Callout type="tip" title="Prefer gap">
  Use `gap` on Flex or Stack for uniform spacing between children. Use Spacer only for one-off
  spacing needs.
</Callout>

<DocsSection title="API">

| Prop   | Type                         | Default      | Description                |
| ------ | ---------------------------- | ------------ | -------------------------- |
| `size` | `string \| number`           | `16`         | Space amount (number → px) |
| `axis` | `"vertical" \| "horizontal"` | `"vertical"` | Sets height or width       |

</DocsSection>
