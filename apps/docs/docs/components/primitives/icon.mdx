<Callout type="info" title="Accessibility">
  **Decorative icons** (no `label`) get `aria-hidden="true"`. **Meaningful icons** require a `label`
  prop which sets `role="img"` and `aria-label`.
</Callout>

<DocsSection title="API">

| Prop    | Type               | Default        | Description                                  |
| ------- | ------------------ | -------------- | -------------------------------------------- |
| `size`  | `string \| number` | `"md"`         | xs=12, sm=16, md=20, lg=24, xl=32, or custom |
| `label` | `string`           | —              | Accessible label (makes icon meaningful)     |
| `color` | `string`           | `currentColor` | CSS color                                    |

</DocsSection>
