<DocsSection title="API">

| Prop        | Type                         | Default | Description                              |
| ----------- | ---------------------------- | ------- | ---------------------------------------- |
| `level`     | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `2`     | Heading depth                            |
| `as`        | `ElementType`                | —       | Overrides level for the rendered element |
| `ref`       | `Ref`                        | —       | Forwarded to heading element             |
| `className` | `string`                     | —       | Merged with internal class               |
| `style`     | `CSSProperties`              | —       | Merged per-property                      |

</DocsSection>
