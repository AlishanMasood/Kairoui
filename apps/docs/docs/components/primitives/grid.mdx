<DocsSection title="API">

| Prop        | Type               | Default | Description                                  |
| ----------- | ------------------ | ------- | -------------------------------------------- |
| `columns`   | `number \| string` | —       | Number → `repeat(n, 1fr)`, string → template |
| `rows`      | `string`           | —       | grid-template-rows                           |
| `gap`       | `string \| number` | —       | Gap between items                            |
| `columnGap` | `string \| number` | —       | Column gap                                   |
| `rowGap`    | `string \| number` | —       | Row gap                                      |
| `align`     | `FlexAlign`        | —       | Align items                                  |
| `justify`   | `FlexJustify`      | —       | Justify content                              |
| `inline`    | `boolean`          | —       | inline-grid                                  |

</DocsSection>
