<DocsSection title="API">

| Prop        | Type            | Default  | Description                |
| ----------- | --------------- | -------- | -------------------------- |
| `as`        | `ElementType`   | `"span"` | Rendered element           |
| `ref`       | `Ref`           | —        | Forwarded to DOM element   |
| `className` | `string`        | —        | Merged with internal class |
| `style`     | `CSSProperties` | —        | Merged per-property        |
| `children`  | `ReactNode`     | —        | Content                    |

</DocsSection>
